Educational video publishing

Curiosity, made clear.

CurioScope Lab Bot is a private creator tool that helps its owner develop original educational videos and publish them to their selected YouTube channel.

How it works

The tool prepares original scripts, video assets, captions, and metadata. With the account owner’s authorization, it uses the YouTube API only to upload and manage the creator’s own videos.

Data and support

CurioScope Lab Bot uses YouTube authorization only to operate the requested publishing workflow. It does not sell personal data or use it for advertising.
